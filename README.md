# Moovz Dash

Jogo de plataforma em estilo corredor, com a temática do app de treino Moovz.

## Créditos

Baseado no [Super Dash](https://github.com/flutter-team-archive/super_dash), criado pelo time do Flutter e pela Very Good Ventures, sob licença MIT (veja [LICENSE](LICENSE)).

## Como rodar

Testado apenas no Android.

```sh
flutter pub get
flutter run --target lib/main_dev.dart
```
